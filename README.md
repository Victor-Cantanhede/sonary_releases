## Como baixar e instalar (Android)

> Requisito: Android 7.0 ou superior.

1. Acesse a aba **Releases** aqui na página do repositório no GitHub.
2. Na versão mais recente, abra a seção **Assets** e baixe o arquivo `.apk` (ex.: `sonary.apk`).
3. Após o download, toque no arquivo `.apk` pelo gerenciador de arquivos ou pela notificação do navegador.
4. Se o Android solicitar permissão para instalar aplicativos de fontes desconhecidas, toque em **Configurações**, ative **Permitir desta fonte** para o navegador ou gerenciador usado e confirme a instalação.
5. Ao concluir, abra o **Sonary** normalmente na sua tela inicial.
